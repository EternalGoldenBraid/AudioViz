Why Currents & Voltages Replace Two-Step Accumulators

Instead of accumulating unconstrained state changes in non-leaky buffers, each sensory residual e_s = y − ŷ(h) is treated as an incoming current integrated over micro-step δt = Δt / M with exact zero-order-hold gain β = (τ_m (1 − exp(−δt/τ_m)) / C) η. When membrane potential v_e or v_h reaches ±θ, it emits a ternary spike ±1 and undergoes subtractive reset v ← v − θs.

Why Biases Are Disabled (bh ≡ 0, bs ≡ 0)

A learned bias b_h ≠ 0 acts as an ideal constant DC current source that never leaks, continually charging v_h to fire 48/48 tonic spikes even when camera observation stops. Similarly, b_s ≠ 0 pins σ(b_s) ≠ 0.5 at h = 0. Disabling biases forces all foveal predictions to be supported by active dynamics through synaptic weights W_s, W_h: when Observe is unchecked, h → 0 and foveal ŷ → 0.5.

Prototype Scope: Retinotopic Fovea vs. Render Cache

Each step advances physical time by one Δt = 1/30 s (forecast() computes the counterfactual no-evidence trajectory; condition() replays [t, t+Δt] from the saved start state when observed). Note that this prototype evolves RC beliefs only for the retinotopic fovea (H=6, K=441): pixels outside the pink circle in the Forecast panel are a static display cache from earlier gaze positions, not an evolving full-world neural field, and Gaussian EIG autonomous gaze is disabled in RC mode.

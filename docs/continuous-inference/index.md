# Inference experiments

Small, recorded experiments for inspecting the continuous inference engine.

| Experiment | Purpose |
|---|---|
| [Node pulses and connection ripples](./dual) | Two synchronized 3D views of the same run: state motion versus directed messages. |
| [Learning and canvas mechanics](./review) | Compare the per-pixel reference and continuous model, including actual weight updates and force-driven canvas motion. |

The recordings are generated locally. Each experiment explains its measurement boundary and reproduction command.

Important distinction: The variance sigma^2 (and its inverse, precision pi = 1 / sigma^2) on this edge describes how noisy or stiff the relationship b ≈ w * f(a) is. Start here: one error, with variance 1

Start with two scalar numbers: a source state a that predicts a target b via b_hat = w * f(a). The prediction error (mismatch) is:

e = b - b_hat = b - w * f(a)

Here f(a) = tanh(a). With variance sigma^2 = 1, the mismatch energy is simply E = 0.5 * e^2. Its derivative with respect to the error is dE/de = e.

If the relationship has residual variance sigma^2, we divide the squared error by sigma^2 (or multiply by precision pi = 1 / sigma^2):

E(a, b, w) = (1 / (2 * sigma^2)) * e^2 = 0.5 * pi * e^2

Differentiating E with respect to the error e gives the precision-weighted error:

dE / de = pi * e = (b - w * f(a)) / sigma^2
Next: derive the state and weight updates, then the matrix form

These are the contributions of this one relationship. A node connected to several relationships receives the sum of their contributions. Unit state and weight learning rates are used here.

Look at where the minus sign lives inside e = (+b) - w * f(a):

1. Target b has a + sign in e:
de/db = +1 => dE/db = +pi * e
Descent: db/dt = -dE/db = -pi * e

If b is inferred and currently above b_hat (e > 0), b is pulled down toward b_hat. If b is clamped (observed sensor), b stays fixed.

2. Source a & Weight w have a - sign in e:
de/da = -w * f'(a) => da/dt = -dE/da = +f'(a) * w * (pi * e)
de/dw = -f(a) => dw/dt = -dE/dw = +(pi * e) * f(a)

In vector/matrix form (b_hat = W f(a), E = 0.5 * e^T Pi e): each source a_i sent predictions down column i of W, so by the chain rule it collects precision-weighted errors Pi * e back up row i of W^T:

da/dt = +f'(a) odot (W^T * Pi * e)
dW/dt = +(Pi * e) * f(a)^T

In continuous_scene_predictive_coding.py:290-389, the interaction energy E_int uses fixed scalar weights on each relationship. The full energy adds the state-rest penalties and multiplies E_int by G = 20 * inference_rate.

e_z = z - W_s @ tanh(h)
# Coupling contribution to E_int:
E_cpl = 0.5 * c_cpl * gamma_z * (e_z.T @ e_z)
# Gradients used by the state integrator:
grad_z = c_cpl * e_z
grad_h = -c_cpl * gamma_z * (W_s.T @ e_z) * dtanh

The state integrator subtracts these gradients. Its block metric divides the raw z gradient by gamma_z, which is why that factor is absent from grad_z. This scaling is not a stored posterior precision.

The clamped camera target is the observation y. The neural potential z remains inferred, including at observed pixels; its visual prediction is sigmoid(z). The observed-pixel error is therefore y - sigmoid(z), with the decoder derivative included in its update.
